Patients Compass · Integration guide

Shopify, configured with care.

A practical checklist for connecting the Patients Compass checkout adapter to the s064cx-hu Shopify store, enabling recurring billing permissions, and validating secure webhook delivery.

Store identity verified orders/paid registered Selling-plan scopes pending
01

Confirm the store

Verify the active connector returns s064cx-hu.myshopify.com before making any catalog or billing changes. Keep the permanent Shopify domain separate from the public Patients Compass domain.

02

Update app permissions

For an organization-owned app, update permissions in the Shopify Partner Dashboard. For a custom app, use Shopify Admin → Settings → Apps and sales channels → Develop apps.

03

Required permission checklist

  • ✓write_products
    Attach selling-plan groups to the Monthly and Yearly products.
  • !write_purchase_options or write_own_subscription_contracts
    Required before Shopify will create recurring selling plans.
  • !Order-information management
    Shopify may require this app permission for purchase-option operations.
  • ✓Storefront checkout scopes
    unauthenticated_read_product_listings, unauthenticated_read_checkouts, and unauthenticated_write_checkouts.
  • !Storefront API / Headless capability
    Enable the Storefront-capable app or sales-channel configuration before creating a Storefront token.
04

Register the webhook

Use one JSON webhook for payment confirmation:

POST /api/shopify/webhook
Topic: ORDERS_PAID
Format: JSON

The endpoint is already registered at https://thepatientscompass.com/api/shopify/webhook.

05

Protect server secrets

Keep these values in encrypted server-side configuration, never in VITE_ client variables:

  • ✓SHOPIFY_WEBHOOK_SECRET
  • ✓SHOPIFY_STOREFRONT_ACCESS_TOKEN
  • ✓Monthly/yearly variant and selling-plan IDs
06

Verify before launch

Run the read-only scope checker with a server-side Admin API token. It prints scope names and status but never prints the token.

cd /home/ubuntu/skills/shopify-patients-compass-setup
export SHOPIFY_ADMIN_STORE_DOMAIN=s064cx-hu.myshopify.com
export SHOPIFY_ADMIN_ACCESS_TOKEN='server-side-token'
python3 scripts/check_shopify_scopes.py

Then send a signed mock orders/paid payload. Expect HTTP 200, and confirm that repeating the same webhook ID is ignored by idempotency protection.
